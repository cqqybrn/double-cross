# 双十字 · Double Cross

一部分支式文字冒险游戏。1940 年 9 月，维也纳犹太裔青年埃里希·瓦尔德作为德国间谍降落在英格兰剑桥郡，当天就走进了警察局。此后五年，他被军情五处翻转，代号"云雀"，替英国给汉堡发了一千多份假情报——闪电战的轰炸损失、一支不存在的美国集团军、V-1 飞弹的落点。他骗了整个德国情报局。他不知道，自己才是被骗得最久的那一个。

全书八章，共 85 话、50 个结局（3 个通关结局：HE·云雀 / HE·勋章 / HE·镜子，其余为死亡或出局结局，每个都有复盘）。

历史事件与机构使用真实名称（闪电战、020 审讯营、XX 委员会、特别行动处、"坚忍行动"、V-1、"超级机密"）；真实人物只在旁白里按史实提及，出场角色全部虚构。

## 怎么玩

- 用浏览器打开 `index.html`，或开启 GitHub Pages 后访问仓库网址。
- 右上角工具栏：**后退**、**台账**（你对汉堡说过的每一句谎，德方会抽查）、**存档**、**结局**、**音乐**。
- 死亡后结局页直接显示提示与「复盘」；卡关时可以「接入静电频道」：英方的黑尔与德方的沃格尔隔着电波一起批改你死在哪一步，还可以「回到那一刻」重新选择。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 构建好的游戏（单文件，SugarCube 2.37.3） |
| `AGENTS.md` | 给 Codex 等代理的素材生成工作说明 |
| `script/00-设定集与大纲.md` | 立意、人物、变量、台账与暗语玩法、分章大纲、跨章分工 |
| `script/chapters/*.md` | 剧本源文件 |
| `script/复盘/*.md` | 每个死亡结局的复盘、静电频道对话和检查点 |
| `assets/` | 素材插槽（`bg/` `char/` `cg/` `bgm/` `sfx/`），清单见 `assets/manifest.json` 与 `assets/README.md` |
| `tools/` | 构建脚本、运行时、样式、素材元数据、自动试玩检查 |

## 构建与检查

```bash
python3 tools/build.py        # 剧本 → index.html，并刷新素材清单
node tools/explore_hua.js     # 逐话走遍所有选项（需要 playwright）
node tools/solve.js "HE·云雀" # 搜索一条打出真结局的路线
```

剧本格式见 `script/00-设定集与大纲.md` 第六节。台账写法：`📒 台账：[101:短名] 一句话`。
