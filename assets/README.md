# 素材插槽说明（给美术 / 音频生成用）

游戏按固定路径加载素材：文件放到下表的路径就会自动出现，缺失的插槽会被安全跳过。
完整清单（含每个插槽的生成提示词）在 `assets/manifest.json`，本文件由 `python3 tools/build.py` 自动生成，请勿手改。

## 总体规范

- **场景背景**（`assets/bg/`，0/5 已就位）：16:9 场景图，JPG，1920×1080，质量 85 左右，单张不超过 600KB。 历史题材写实插画。故事主体发生在 1940–1945 年战时的伦敦，少数场景在汉堡、巴黎、维也纳或战后年代，以下面的场景描述为准。低饱和、偏冷的色调，轻微胶片颗粒，构图像 1940 年代的新闻照片或电影剧照。画面中不要出现可读文字、水印或现代物品；人物如需出现只作远景剪影，不画清晰面孔。
- **事件插图**（`assets/cg/`，0/0 已就位）：16:9 事件插图，JPG，1920×1080。 与背景同一画风的事件插图，可以有人物，但人物外貌须遵守角色设定。
- **人物立绘**（`assets/char/`，0/10 已就位）：半身立绘（腰部以上），透明背景 PNG，1024×1536，人物居中，头顶留约 8% 空白。游戏里会把它裁成圆形头像（取上方 40%），所以脸要在画面上部三分之一处。 与背景统一的写实插画风，统一左上方光源。同一人物的所有表情、服装必须保持脸型、五官、发型和年龄一致：先生成「常态」，再以它为参考生成其他表情。
- **配乐**（`assets/bgm/`，0/5 已就位）：MP3，128–192kbps，立体声。可无缝循环，长度 60–150 秒；首尾音量一致以便循环。 原创配乐，不要使用或模仿任何已有曲目的旋律。
- **音效**（`assets/sfx/`，0/3 已就位）：MP3，单声道即可，0.5–4 秒，开头不留空白，结尾自然衰减。 写实音效，1940 年代环境（没有现代电子声）。

## 生成流程建议

1. 先按「人物设定」为每个角色生成 `常态` 立绘，确定长相后，再以它为参考图生成其余表情和服装，保证同一人物前后一致。
2. 背景按地点分批生成，同一地点的不同时间（白天/夜/雪…）用同一构图，只改光线和天气。
3. 配乐需可无缝循环；音效开头不留空白。
4. 放好文件后运行 `python3 tools/build.py`，清单里的 `present` 会更新为 true，然后提交。

## 人物设定

- **埃里希**：主角埃里希·瓦尔德，男，28–33 岁（1940–1945），维也纳犹太裔。瘦高，黑发向后梳，额头高，灰眼睛，神情克制而疲惫；穿旧的深灰色西装和毛衣背心，左手无名指习惯性地被右手摩挲。1975 年时 63 岁，白发，仍然瘦。
- **黑尔**：玛格丽特·黑尔，女，34 岁，军情五处案件官。深棕色短发一丝不乱，细框眼镜，灰色套装，手里常拿一支红笔；表情冷静、微带讽意。1975 年 69 岁，白发，开衫。
- **斯坦顿**：斯坦顿少校，男，50 岁，020 号营营长。笔挺的英军制服，右眼夹单片眼镜，修剪整齐的小胡子，神情礼貌而冷酷。
- **芬奇**：哈里·芬奇，男，26 岁，军情五处报务员，伦敦东区出身。圆脸、雀斑、乱翘的棕发，衬衫袖子卷起，脖子上挂着耳机。
- **默里太太**：默里太太，女，60 岁，肯蒂什镇的房东寡妇。灰发挽髻，围裙，羊毛开衫，慈祥而唠叨。
- **艾达**：艾达·默里，女，22–25 岁，克罗伊登军工厂女工。浅棕色卷发包在头巾里，工装或碎花连衣裙，脸上有机油渍，笑起来很直爽。
- **沃格尔**：卡斯滕·沃格尔，男，45 岁，汉堡情报局联络官。稀疏的金灰色头发，圆框眼镜，略胖，穿德军情报军官便服或战俘营的旧外套，神情温和而疲倦。
- **克勒**：汉斯·克勒，男，30 岁，德国间谍，真心的纳粹党员。金发平头，方下巴，冷蓝眼睛，穿被捕时的英式便装。
- **克莱尔**：克莱尔·杜布瓦，女，25 岁，法国人，SOE 无线电发报员。黑色短发，眼睛很亮，瘦削，穿英式便装或巴黎的旧大衣，神情坚毅中带一点玩笑。
- **莉亚**：莉亚·瓦尔德，女，58 岁，埃里希的母亲，钢琴教师。灰发挽髻，黑色长裙，手指修长。
- **汉娜**：汉娜·瓦尔德，女，19 岁，埃里希的妹妹，想学医。深色长发编辫，戴眼镜，膝上摊着解剖学课本。
- **灰大衣**：德国情报局在维也纳的联络人，男，40 岁，灰色大衣，礼帽拿在手里，面目平常、礼貌。
- **老警察**：剑桥郡乡村的老警察，男，60 岁，白胡子，制服，手里拿着水壶。
