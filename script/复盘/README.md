# 复盘与补课（静电频道）

每个死亡 / 出局结局有三层提示：

| 层 | 在哪里 | 写在哪 |
|---|---|---|
| 第一层 | 结局页，直接显示 | 剧本里结局后面的 `💡 提示：` 行（氛围化的一句话） |
| 第二层 | 结局页，直接显示 | 本目录的 `复盘：` 行：讲清楚为什么死，以及大方向 |
| 第三层 | 结局页的「接入静电频道」按钮，玩家自愿进入 | 本目录的补课对话：黑尔与沃格尔隔着电波一起批改，明确指出死在哪一步、正确做法 |

本目录每章一个文件（`01-序章.md` … `08-终章.md`），由 `tools/build.py` 读入，按结局名匹配。**不要改剧本正文。**

## 静电频道

一个只有静电声的无线电频道，不在任何时间、任何地方。两位联络官——英方的玛格丽特·黑尔和德方的卡斯滕·沃格尔——在剧情里从未见过面，在这里隔着电波一起复盘他们共同的间谍。

- **【黑尔】**：用红笔批改，像剑桥的导师批改论文，精确、冷、偶尔一句干燥的英式挖苦。她打分。
- **【沃格尔】**：北德人，像老派的中学老师，温和、啰嗦、爱讲道理，偶尔一句冷笑话；负责把正确做法讲明白，可以直接说出选项原文。
- 两人偶尔互相挖苦（"您的人也不怎么样，黑尔小姐。""至少我的人还活着，沃格尔先生。"），但都在乎这个学生。
- 剧情后段才揭晓的事（伪造的家信、英方早已知情），在补课里**不要剧透**。

## 格式

```
## 结局名（与剧本里 ★【剧终】 后面的名字完全一致）
复盘：两三句。第一句说清楚这一死的因果逻辑；后面给方向。延迟死亡要点出源头在哪一章、哪一类选择。
检查点：第N话｜选项原文
检查点名：第X章·一句场景描述
数值：001,002
评分：丁
【黑尔】……
【沃格尔】……
```

- **复盘**（必填）：直接显示在结局页。不要谜语。
- **检查点**（可多行）：`第N话` 是那组选项所在的话号；`选项原文` 是那组选项里任意一个选项的原文（与剧本 `◆[...]` 完全一致）。选能纠正这次死亡的那个选择点；延迟死亡指向埋坑的源头。
- **检查点名**：按钮文字，与检查点一一对应。
- **数值**（可选）：相关变量编号，补课页显示玩家死时的数值。
- **评分**：甲 / 乙 / 丙 / 丁，黑尔给的分（甲 = 差一点就对了；丁 = 低级错误）。
- **补课对话**：4–8 句，可用 `【旁白】` 写一两句静电、杂音之类的动作。读完必须知道死在哪一章的哪一步、为什么、该怎么选。
